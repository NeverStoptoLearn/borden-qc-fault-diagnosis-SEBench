# Borden QC Fault Diagnosis Package

Artifacts:

- `borden_qc_fault_diagnosis_public_task_bundle.zip`: public work-container bundle.
- `borden_qc_fault_diagnosis_private_judge_bundle.zip`: judge bundle with hidden labels.
- `tasks/borden_qc_fault_diagnosis.json`: SE-Bench task definition.
- `scripts/choose_ports.py`: checks 8000/8080 and chooses fallback ports.
- `scripts/start_asset_server.py`: serves bundles on 8000 or fallback asset port.
